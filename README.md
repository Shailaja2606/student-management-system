# Student Management System
## Project Description
The Student Management System is a Linux-based application developed using Shell Scripting. It helps manage student details, attendance, and examination results through a simple menu-driven interface.
The project uses Git and GitHub for version control and AWS EC2 for cloud deployment
## Technologies Used
- Linux (Ubuntu)
- Bash Shell Scripting
- CSV files for data storage
- Git
- GitHub
- AWS EC2

## Features
1. Add Student
2. View All Students
3. Search Student
4. Update Student
5. Delete Student
6. Mark Attendance
7. View Attendance
8. Calculate Attendance Percentage
9. Add Examination Results
10. View Examination Results
11. Calculate Academic Performance
12. Generate Complete Student Report
13. Exit

## Installation and Execution
